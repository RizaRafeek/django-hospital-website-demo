Django static files:
    the web application might also need to serve additional files like images, js, css necessary to render the complete
    web page
    these are static files


    to add them:
        create seperate folders under a folder called static directly inside the root directory:
            -css
            -js
            -images

        add your style.css inside css
        then  settings.py   ->    under static url   -> write STATICFILES_DIRS = [
                                                                                   os.path.join(BASE_DIR, static) 
                                                                                    ]
        in base.html :
            {% load static %}
            <link rel="stylesheet" href="{% static '/css/style.css' %}">


        position : relative:
            set this container as the reference position(parent)
        position absolute :
            place flexibily with the css properties mentioned within the parent container


        Assigning multiple classes to the same element:
            "carousal-img active"
            in css:
                "carousal-img"  -> apply css styling   -> everything having this class will have this styling

                ".carousal-img.active  -> apply this styling to only those one swhose class is "carousal-img active"

            this way we can apply the common proportiex ut still give special properties to some of the elements



Django models:
    represents table in our database
    -django create a database when we create the project
    -models defined in app/models.pys

    To create:
        class TableName(models.Model):
            column name = models.

        then you should migrate:
            python manage.py makemigrations

            python manage.py migrate

    register the models:
        admin.py : import the models
            admin.site.register(TableName)

        then you can add your TableName table data in the admin dashboard itself


        whenever you make any changes : dont forget to run the two commands of migrations

        you have to register your models in the admin.py as well

To render the model as form:
    create a forms.py    ->    import the model and create a class with the required field names
    views.py : add that under that specific function rendering that page


    to create a datepicker:
        create a class in forms.py
        add that class as value for  key in dictionary widgets under the class Meta


    to change the label names from the variabel to the way we want
        create labels dictionary below widgets:
            key : the model field name
            value : the name we want to give the fields
